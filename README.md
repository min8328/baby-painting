# 아기 색칠공부

`index.html` 파일 하나로 된 색칠 종이입니다. 크롬으로 이 파일을 열면 되고, 따로 설치할 프로그램은 없습니다. 카페24 같은 일반 호스팅에는 이 파일만 올리면 됩니다. 색칠 계산은 여는 브라우저 안에서 돌아갑니다.

위는 하얀 백지이고, 아래에는 빨강, 주황, 노랑, 초록, 파랑, 남색, 보라, 분홍, 검정, 하양 동그라미가 있습니다. 글자로 된 색 이름은 없습니다. 컴퓨터에서 붓은 지름 20픽셀이고, 모바일에서는 그 절반입니다. 나중에 칠한 색이 그대로 덮습니다. 휴대폰을 돌려도 그린 그림은 늘어나지 않고, 하얀 배경을 늘리거나 잘라 맞춥니다.

## 쓰는 법

1. 아래 동그라미를 누릅니다. 숫자 키 1부터 9는 빨강부터 검정까지이고, 하양은 마지막 동그라미입니다.
2. 하얀 종이 위를 문질러 칠합니다.
3. 붓 버튼은 지금 굵기의 2.5배 붓과 원래 붓을 오갑니다. 버튼 그림은 누르면 바뀌는 붓이고, 커서도 그 붓 모양으로 바뀝니다.
4. 귀퉁이가 접힌 종이 버튼은 지금 그림을 지우고 새 종이를 엽니다. 그 버튼을 2초 이상 누르면 그림을 저장합니다. 되돌리기로 돌아올 수 있습니다.
5. 네 칸 아이콘을 누르면 템플릿 창이 바로 열립니다. 그 버튼을 2초 누르면 손을 떼기 전에 전체 화면이 되고, 전체 화면에서 다시 2초 누르면 창으로 돌아옵니다. 토끼, 고양이 같은 밑그림을 고르면 새 종이에 선이 깔리고, 그 위에 칠해도 선은 그대로 보입니다.
6. `Z`는 되돌리기, `F`는 전체 화면입니다. 전체 화면과 모바일에서는 붓 커서가 따라오고, 손을 떼도 마지막 자리에 남습니다.
