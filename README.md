# 아기 색칠공부

`index.html` 파일 하나로 된 색칠 종이입니다. 크롬으로 이 파일을 열면 되고, 따로 설치할 프로그램은 없습니다. 카페24 같은 일반 호스팅에는 이 파일만 올리면 됩니다. 색칠 계산은 여는 브라우저 안에서 돌아갑니다.

위는 하얀 백지이고, 아래에는 빨강, 주황, 노랑, 초록, 파랑, 남색, 보라, 검정, 하양 동그라미가 있습니다. 글자로 된 색 이름은 없습니다. 컴퓨터에서 붓은 지름 20픽셀이고, 모바일에서는 그 절반입니다. 나중에 칠한 색이 그대로 덮습니다. 휴대폰을 돌려도 그린 그림은 늘어나지 않고, 하얀 배경을 늘리거나 잘라 맞춥니다.

## 쓰는 법

1. 아래 동그라미를 누릅니다. 숫자 키 1부터 9도 같은 순서입니다.
2. 하얀 종이 위를 문질러 칠합니다.
3. 되돌리기는 마지막 획을 취소하고, 지우기는 종이를 하얗게 비웁니다. 하양으로 일부만 덮을 수도 있습니다.
4. 저장은 칠한 그림을 PNG로 받습니다.
5. 전체 화면을 누르면 창을 꽉 채웁니다. `F` 키도 같고, `Z`는 되돌리기입니다. 전체 화면에서는 마우스 커서가 큰 붓으로 바뀌고, 모바일에서는 손가락을 누르는 동안 붓이 따라옵니다.
6. 컴퓨터와 모바일 가로 화면에서 되돌리기, 지우기, 저장, 전체 화면은 오른쪽 아래 밭전자입니다. 휴대폰 세로 화면에서는 색 동그라미 아래 한 줄입니다.
